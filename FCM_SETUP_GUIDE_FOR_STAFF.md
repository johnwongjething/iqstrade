# FCM Setup Guide for Staff & Managers

## Quick Setup Instructions

### For Staff/Managers who need to receive notifications:

1. **Login to the system** with your staff account
2. **Go to Dashboard** (after login)
3. **Click "🔔 Setup Notifications"** button (only visible to staff/admin users)
4. **Follow the setup wizard**:
   - Grant notification permission when prompted
   - Your device will be automatically configured
   - Test notification will be sent to verify setup

### What you'll receive notifications for:

- ✅ **New Customer Emails** - When customers send emails
- ✅ **Payment Receipts** - When payment confirmations are processed
- ✅ **System Alerts** - Important system notifications

### Troubleshooting:

**If you don't receive notifications:**
1. Check that notifications are enabled in your browser settings
2. Make sure you're using a supported browser (Chrome, Firefox, Safari)
3. Try refreshing the page and running setup again

**If you receive duplicate notifications:**
- This is normal and doesn't affect functionality
- The system is working correctly

### Supported Devices:
- ✅ Mobile phones (Android/iOS)
- ✅ Tablets
- ✅ Desktop computers
- ✅ Laptops

### Browser Requirements:
- ✅ Chrome (recommended)
- ✅ Firefox
- ✅ Safari
- ✅ Edge

## Technical Details (For IT Staff)

The FCM system uses:
- **Firebase Cloud Messaging** for push notifications
- **Service Workers** for background processing
- **Web Push API** for browser notifications

No app installation required - everything works through the web browser.
