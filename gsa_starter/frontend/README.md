# GSA System Frontend Starter

This folder is the starting point for your React frontend for the GSA ticketing system.

## Structure
- `src/` — React source code
  - `pages/` — Main pages (Dashboard, Booking, Flights, etc.)
  - `components/` — Reusable UI components
  - `config.js` — API base URL and environment config
  - `App.js` — Main app entry point and router
- `public/` — Static assets (index.html, images, etc.)
- `package.json` — NPM dependencies

## Next Steps
1. Install dependencies:
   ```bash
   npm install
   ```
2. Set your API base URL in `src/config.js`.
3. Build out pages and components for each module (flights, bookings, payments, etc.).
4. Connect to backend APIs for data.
5. Add authentication and role-based navigation.
6. Test locally and iterate!

---

This frontend is designed to be modular, mobile-friendly, and easy to extend as your business grows.
