# GSA System Starter Kit

This folder contains a project starter kit for a single-airline (Lao Airlines) GSA ticketing system. It includes:

- Database schema (PostgreSQL)
- Backend and frontend project scaffolding
- Clear separation of modules for easy extension

## Structure

- `db/` — Database schema and migrations
- `backend/` — Flask backend starter (APIs, models, config)
- `frontend/` — React frontend starter (pages, components, config)

## How to Use

1. **Review the database schema in `db/GSA_DB_SCHEMA_STARTER.sql`**
2. **Set up the backend**: Start with the Flask app in `backend/`
3. **Set up the frontend**: Start with the React app in `frontend/`
4. **Extend modules as needed**: Add features, endpoints, and UI as your business grows
